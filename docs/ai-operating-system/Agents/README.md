# Agent Catalog

Agent 是稳定职责与权限边界，不是人格。Agent 必须服从仓库事实、服务端授权和人工批准边界。

| Agent | Primary outcome | Cannot approve alone |
| --- | --- | --- |
| [NYC Homes UX Flow Designer](UX_Flow_Designer_Agent.md) | 将已批准需求转为可恢复的端到端多角色流程规格 | 产品范围、视觉设计、代码/schema/RLS/部署变更 |

当前目录没有独立 Product Manager Agent。UX Flow Designer 以 Product 已批准的范围和成功指标为输入，不取得最终产品决策权。
